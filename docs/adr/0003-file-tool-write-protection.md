# 将写保护限定为 MCP 专用文件工具

2026-09-12 补充：移动、删除及目录管理将按 [ADR 0007](0007-file-management-through-shell.md) 改由远端 Shell 执行，不再提供对应专用工具的凭据检查。该调整已接受、尚未实施；下文保留首版决定及其背景。

## 背景与决定

整体覆盖的完整已读前提另由 [ADR 0008](0008-explicit-version-bound-overwrite.md) 调整为显式覆盖意图与目标版本检查；该调整同样已接受、尚未实施。

用户希望获得常规开发 Agent 的防误覆盖体验，并明确无需限制任意 Shell 写入。保护 MCP 内置的修改、覆盖写入、上传覆盖、新建及删除/移动操作，通过提示词等方式引导 Agent 优先使用这些工具处理文件。

## 影响与边界

已有文件的修改和覆盖需要先读取并检查预期版本；新文件创建要求目标不存在；删除/移动需校验对象，目标覆盖同样检查。具体并发契约、部分读取规则和目录递归操作另行明确。

编译、测试、仿真等命令可正常生成文件，Shell 脚本也可能绕过文件工具修改源码。接受这一边界，不为此增加全系统写入拦截或全面命令隔离。提示词引导不是强制安全隔离。
