# 优先通过 ZCode 原生后台 Shell 回传完成结果

## 背景与决定

用户需要远端任务不阻塞主 Agent，且结束后主动触发后续处理，不能仅依赖 Agent 记住任务编号。用户确认 ZCode 原生后台 Shell 已有完成回传机制，因此优先让 Agent 以后台方式调用 Shell，运行本机等待程序并在远端任务结束时返回结果，不为单纯等待额外运行子代理。

## 影响与边界

该方案需要 MCP 能力之外的本机命令入口和接入指引，并依赖 ZCode 自身的后台任务生命周期。程序负责状态等待，主模型无需持续查询。ZCode 的完成唤醒行为目前依据用户说明，必须在目标版本验证。

本机等待程序的接口、与 MCP 核心共享状态的方式、启动与等待登记的一致性、客户端退出后的恢复尚未定案。只在 Shell 命令末尾加 `&` 不视为完成 ZCode 后台接入。此决定不承诺其他客户端有相同完成回传能力。
