# 将远端离线、无 root 与旧版 glibc 作为兼容约束

## 背景与决定

用户于 2026-09-10 明确：实际开发环境在只能通过 SSH 访问的 CentOS 7，无法联网、没有 root 权限，必须照顾旧版 glibc。远端部署方案必须满足这些约束，不以在线安装依赖、root 操作或升级系统 glibc 为前提；用户表示其他方面应该没有限制。

## 影响

可以考虑在用户目录离线放置辅助脚本或兼容的可执行文件。若引入新依赖，需要准备可搬运的离线包并验证目标兼容性，增加打包与测试工作；也可以优先利用远端现有能力。尚未选定语言、运行时、常驻进程或安装目录，Win11 的联网能力亦未确认。
