# ZCode 重启后在继续原对话时恢复跟进

用户接受：ZCode 重启后，不要求仅启动应用便自动唤醒原对话；在用户继续原对话时，由恢复钩子自动提供未完成任务和未处理结果，Agent 再重新安排后台等待。用户不必记住或提供任务编号。

采用 UserPromptSubmit 作为已验证的恢复触发位置。运行中任务重新挂接等待，已结束任务提供结果；这不是重新执行远端命令。原生后台完成通知仍负责正常运行时的自动续步。

阶段 0 已用隔离 ZCode 3.11.2 所附 runtime 验证钩子信息进入原会话并重建后台回传。真实持久任务清单、不同对话隔离、去重及结果确认仍需后续实现与测试；提示词注入本身不作为这些要求已完成的证据。
