# 移动、删除及目录管理统一使用远端 Shell

## 状态

2026-09-12 用户明确接受。2026-09-13 已随 [票据 #20](https://github.com/ONEGAYI/ssh-mcp-server/issues/20) 实施：四个 MCP 工具与远端 helper 动作分发已移除，专用调用路径不再存在。

本决策调整 [ADR 0003](0003-file-tool-write-protection.md) 中移动与删除的专用文件工具保护范围，其他文件工具的保护规则不因此改变。

## 背景

[Issue #3](https://github.com/ONEGAYI/ssh-mcp-server/issues/3) 提议移除低频文件管理工具，减少 MCP 工具列表的上下文负担。已有远端 Shell 命令入口能够承担这些操作，且 Shell 原本不受文件工具的 readToken 检查约束。

## 决定

- 移除 `remote_move`、`remote_delete`、`remote_mkdir`、`remote_rmdir`，使用远端操作系统对应的 Shell 命令执行移动、删除、创建目录及删除空目录。
- 用户接受移动和删除不再由专用工具强制检查已读凭据、已读完整范围与文件版本；防误操作依靠 Agent 操作规范及所在客户端的命令审查机制，不将其表述为等价的工具级保护。
- 不新增 Shell 写入拦截、影子凭据检查或功能等价的新 MCP 工具来重新引入上述门槛。保留已有命令入口的权限与验证规则。
- 文件读取、精确编辑、创建与整体覆盖工具的已确认规则继续适用。本决策不决定整体覆盖大文件的授权方式。
- 实施时同步移除专用入口及无其他用途的实现，更新相关测试、工具清单和使用指引，明确使用远端平台适用的命令。

## 影响与边界

- 减少四个 MCP 工具，已使用这些工具名的调用方需要改用命令入口。
- 移动和删除失去原有工具强制的读后写与版本检查。命令日志只提供执行记录，不代替变更前验证或自动恢复。
- 移除工具不会自动为任何具体删除、覆盖或递归操作授予用户授权；实际操作仍遵循当前任务范围和用户指令。
- 当前任务执行器仍按 Linux 环境实现；本决策不构成已支持远端 Windows Shell 的证据。
