# 为已有绑定提供二次配置入口

## 状态

2026-09-13 用户确认本轮纳入二次配置能力。尚未实施；当前 remote_setup 只允许相同 profile 重复配置，内容不同会返回 SETUP_CONFLICT，不是增量更新接口。

## 背景

空间额度、保留期限及搜索行为需要在初次接入后调整。要求用户重填全部 SSH 信息或直接修改配置文件，不利于保留已有绑定与恢复状态。与此同时，更换服务器或状态目录可能改变身份及状态定位，不能等同于调整普通参数。

## 已确认决定

- 提供针对已有绑定的二次配置能力。更新前读取现有配置，只修改用户指定字段，保留其余设置；不把未提供字段重置为默认值。
- 普通更新覆盖额度、保留期限等策略参数。更新应明确对应哪个绑定，避免影响同一本机项目下的其他远端绑定。
- 已确认额度、保留期限、搜索选项等普通策略参数无需重启：保存后在下一次操作或维护周期读取新值，不打断已经执行中的任务和传输。保存结果须明确说明该生效时点，不能表述为强制即时切换所有正在运行的操作。
- 保留期限调整不追溯已有记录：已有记录保持原定到期时间，新生成的记录使用新期限。例如从 30 天改为 3 天，不因此提前删除已有历史记录。已有记录续期与状态转换时的策略关联细节在规格中明确，不能借配置刷新隐式重算其原到期时间。
- 更换服务器或状态目录在本轮通过新建绑定处理，保留旧绑定用于完成旧任务和清理旧状态；不做自动迁移，也不能直接覆盖旧配置后令任务、读取凭据或续传记录失联。普通策略更新仍使用原绑定的二次配置入口。
- 沿用配置冲突检查和受控写入，不静默覆盖并发修改；不回传 SSH 密码、私钥等敏感内容，也不因普通策略更新重写认证信息。

## 影响与待定项

- 同一绑定可在保留其余配置的情况下调整策略，首次创建与重复相同配置的既有使用方式继续兼容。
- 配置结构、普通策略以外字段的重载边界及降低额度低于现有占用时的具体预留处理留待规格确定。自动迁移不在本轮范围内。
- 本项只确认二次配置能力，不表示现有服务已经支持自动重载，也不替代尚未实施的大文件与清理功能。
